# Skybox Creator

Single-file browser tool that builds an equirectangular 360° panorama (8192×4096 JPG) for Enscape / V-Ray / Corona skyboxes from 1–4 site photos.

## Usage

1. Download `skybox_creator.html` (the GitHub preview only shows raw code — it won't run there).
2. Double-click to open it in Chrome or Edge.
3. Drop in 1–4 photos by direction (N/E/S/W). Optionally add a background photo — it fills any empty quadrants (or all four if used alone).
4. Tune seam blend, band height, horizon position and sky/ground fade with the sliders. Use ▲/▼ on each photo to shift it vertically, × to remove it.
5. Generate, check the 360° preview, and download the panorama.

Everything runs locally in the browser. Nothing is uploaded, and it works offline.
